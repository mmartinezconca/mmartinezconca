## 🗺️ Featured Project
### Chile Seismic Risk Map (QGIS)
A national-scale GIS project visualizing earthquake density and exposure across Chile using kernel density estimation.

**Key elements:**
- Earthquake point data → KDE surface
- Percentile-based classification for interpretability
- Integrated tectonic context, urban areas, and major cities
- Multi-scale design with national map and regional inset

➡️ **Repository:** https://github.com/mmartinezconca/chile-seisimic-context-map
